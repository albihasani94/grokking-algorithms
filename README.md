# Grokking Algorithms (2nd Edition)

Java implementations and exercises from [Grokking Algorithms, 2nd Edition](https://www.manning.com/books/grokking-algorithms-second-edition).

## Prerequisites

- Java 25
- Maven 3.9+

## Getting started

```bash
mvn compile
mvn test
```

## Project structure

```
src/main/java/    # Algorithm implementations
src/test/java/    # Tests
```
